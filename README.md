📊 Customer Insights & Revenue Analytics

 End-to-End Data Analytics Project | Python • SQL • Power BI

📌 Overview

This project delivers an end-to-end customer analytics solution to understand purchasing behaviour, customer value, and revenue performance.

The objective was to transform raw transactional data into actionable business insights using Python, SQL, and Power BI.

This project demonstrates real-world data cleaning, analysis, and dashboard development skills required for Data Analyst roles.

Dataset

The dataset contains 3,900 retail transactions with customer, product, and purchase information.

Key features include:

👤 Customer demographics (Age, Gender, Subscription Status)

🛍 Purchase details (Product, Category, Purchase Amount)

⭐ Customer feedback (Review Rating)

🚚 Shipping and behavioural data

Missing values were cleaned and handled during preprocessing.

 Project Workflow
1️ Data Cleaning (Python)

Loaded and explored dataset using Pandas

Handled missing values

Created new features (Age Groups, Customer Segments)

Prepared clean dataset for analysis

2️⃣ Data Analysis (SQL)

Analysed business performance using SQL:

Revenue analysis by customer segment

Customer segmentation (New, Returning, Loyal)

Top-performing products

Subscription impact on revenue

Revenue contribution by age group

3️⃣ Dashboard Development (Power BI)

Built an interactive business dashboard to track:

✔ Total Revenue
✔ Revenue per Customer
✔ Customer Segments
✔ Category Performance
✔ Age Group Analysis

📸 Dashboard Preview

 Key Business Insights

💡 Young Adult customers generate the highest revenue

💡 Loyal customers contribute the majority of sales

💡 Accessories and Clothing are top-performing categories

💡 Subscribers show strong revenue contribution

💡 Express shipping customers have higher average spend
